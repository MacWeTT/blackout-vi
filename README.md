# GTA VI Spoiler Shield

Chrome extension (MV3) that hides GTA VI spoilers on YouTube before they paint.

- Load: `chrome://extensions` → Developer mode → Load unpacked → pick this folder.
- Test: `node test/classifier.test.js`
- Layout: `src/core` (word lists, classifier), `src/content` (YouTube script and styles), `src/popup`, `assets`, `docs/HANDOFF.md`.
